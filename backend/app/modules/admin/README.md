# modules/admin

> Статус: каркас. Реализация — §13, этапы 1 и 6.

**Назначение:** Админ-роутеры поверх модулей: дашборд, пользователи, чаты, входы, инциденты, лимиты, БЗ, сценарии, модели, инструменты, настройки, диагностика AD.

**Публичный интерфейс:** `/api/admin/*`.

**Зависит от:** все модули; каждое действие над чужими данными — в `audit`.

**Точки расширения:** Новая страница — `docs/guides/add-admin-page.md`.

**Данные:** `app_settings`.

**Тесты:** `backend/tests/unit/admin/`, `backend/tests/integration/admin/`; запуск — `make test`.
