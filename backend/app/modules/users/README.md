# modules/users

> Статус: каркас. Реализация — §6.5, §11.1, этап 1.

**Назначение:** Профиль пользователя: атрибуты и фото из AD, синхронизация, форма обращения, личные настройки.

**Публичный интерфейс:** `GET/PATCH /api/profile`, `GET /api/profile/photo`; периодическая синхронизация с AD (worker).

**Зависит от:** `auth`, `rbac`; AD.

**Точки расширения:** Новое поле профиля — маппинг в `ldap.attributes` + миграция (§5, карта изменений).

**Данные:** Таблица `users`.

**Тесты:** `backend/tests/unit/users/`, `backend/tests/integration/users/`; запуск — `make test`.
