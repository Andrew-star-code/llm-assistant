# modules/incidents

> Статус: каркас. Реализация — §9.6, §13.5, этап 7.

**Назначение:** Инциденты: системные ошибки с захватом логов, скрытые репорты модели, вердикты guard-модели, безопасность, здоровье моделей.

**Публичный интерфейс:** `create_incident(...)`; админ-API инцидентов.

**Зависит от:** `audit`.

**Точки расширения:** Новый тип инцидента — enum + фильтры админки.

**Данные:** `incidents`, `incident_comments`.

**Тесты:** `backend/tests/unit/incidents/`, `backend/tests/integration/incidents/`; запуск — `make test`.
