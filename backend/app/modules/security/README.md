# modules/security

> Статус: каркас. Реализация — §13.4, этапы 1 и 7.

**Назначение:** Журнал входов, правила подозрительности, блокировки пользователей и IP, завершение сессий.

**Публичный интерфейс:** Сервис проверки перебора; админ-API «Входы и безопасность».

**Зависит от:** `auth`, `incidents`; Redis.

**Точки расширения:** Новое правило — класс правила + порог в конфиге.

**Данные:** `login_events`, `ip_blocks`.

**Тесты:** `backend/tests/unit/security/`, `backend/tests/integration/security/`; запуск — `make test`.
