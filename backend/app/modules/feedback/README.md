# modules/feedback

> Статус: реализовано на этапе 2 (§7.4); раздел админки «Обратная связь» — этап 6
> (`admin/feedback_router.py`).

**Назначение:** лайк и дизлайк ответа ассистента с причинами (неточно, не по теме, ошибка в коде,
неполно, другое) и комментарием. Одна оценка пользователя на ответ.

**Публичный интерфейс:** `PUT /api/messages/{id}/feedback` (`{rating: 1|-1, reasons, comment}`;
причины сохраняются только у дизлайка), `DELETE /api/messages/{id}/feedback`. Оценка пользователя
приходит в `MessageOut.feedback`.

**Зависит от:** `chats` (проверка владельца сообщения).

**Точки расширения:** список, статистика по причинам и выгрузка XLSX — админка «Обратная связь»
(`GET /api/admin/feedback`, фильтр по оценке и причине; «неточно» у ответов с RAG разбирают там же,
§10.6).

**Данные:** `feedback` (уникальность `message_id, user_id`).

**Тесты:** `backend/tests/integration/test_chat.py::test_feedback`.
