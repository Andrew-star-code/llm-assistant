# Порядок действий при инциденте информационной безопасности

При подозрении на фишинговое письмо не открывайте вложения и не переходите по ссылкам.
Перешлите письмо на адрес security@company.local и удалите его.

Если компьютер заражён вредоносным ПО (malware, ransomware), немедленно отключите сетевой кабель
и сообщите в службу информационной безопасности по телефону 1234.
