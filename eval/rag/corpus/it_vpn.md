# Инструкция: удалённый доступ через VPN

## Подключение
Для удалённой работы используйте клиент OpenVPN. Конфигурационный файл выдаёт служба ИТ-поддержки.
Для входа нужна двухфакторная аутентификация (2FA) через приложение-аутентификатор.

## Проблемы с подключением
Если VPN не подключается, проверьте интернет-соединение и время на компьютере: при расхождении
более пяти минут 2FA-код не принимается. Ошибка TLS handshake failed означает устаревший конфиг.
