# config/templates

Шаблоны генерации файлов (§9.4). Замена файла меняет оформление без правок кода; в образ api и
воркера каталог монтируется вместе с `config/`.

| Файл | Для чего | Как сделать свой |
| --- | --- | --- |
| `reference.docx` | DOCX и PDF из `create_document`: стили заголовков, абзацев, таблиц, поля страницы | Открыть в Word, поменять **стили** (не текст): «Заголовок 1–3», «Обычный», «Таблица» и т. д. Исходник — `pandoc -o reference.docx --print-default-data-file reference.docx` |
| `presentation.pptx` | PPTX из `create_presentation`: макеты 0 — титульный, 1 — заголовок и текст, 2 — раздел | Корпоративный шаблон PowerPoint с тем же порядком макетов; слайды из файла шаблона удалить |

Сейчас лежат нейтральные шаблоны pandoc и python-pptx — корпоративные пока не переданы
(вопрос в `docs/status.md`).
