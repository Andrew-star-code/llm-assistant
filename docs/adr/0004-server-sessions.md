# 0004. Серверные сессии: cookie HttpOnly + Redis

- Статус: принято
- Дата: 2026-10-31

## Контекст

Админ должен мгновенно завершать сессии и блокировать пользователей (§6.4, §13.4).

## Решение

Непрозрачный id сессии в cookie `HttpOnly; Secure; SameSite=Lax`, данные — в Redis, история — в
таблице `sessions`. CSRF — double submit на все изменяющие запросы.

## Альтернативы

JWT в localStorage: токен можно украсть через XSS, мгновенный отзыв требует чёрного списка — то есть
того же серверного хранилища.

## Последствия

Каждый запрос читает сессию из Redis (дёшево). Фронтенд обязан передавать CSRF-заголовок.
