# 0009. Файлы — том на диске за интерфейсом Storage

- Статус: принято
- Дата: 2026-10-31

## Контекст

Сервер один; файлы — загрузки, документы БЗ, сгенерированные файлы, выгрузки.

## Решение

Том на диске, доступ только через интерфейс `Storage` (`core/storage`), ключи — случайные
(имя файла никогда не используется как путь, §15).

## Альтернативы

Объектное хранилище (S3/MinIO) с первого дня — лишний сервис без выигрыша на одном сервере.

## Последствия

Переход на S3 — новая реализация `Storage` без изменения модулей (FUTURE). Бэкап — rsync (§16.7).
