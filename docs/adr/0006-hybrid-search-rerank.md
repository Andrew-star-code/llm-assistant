# 0006. Гибридный поиск BM25 + dense с реранкером

- Статус: принято
- Дата: 2026-10-31

## Контекст

Векторный поиск промахивается по точным номерам договоров, кодам и фамилиям; BM25 — по перефразам.

## Решение

В каждой коллекции — один запрос Query API: prefetch `dense` (bge-m3) и `bm25` (считает сам Qdrant,
`qdrant/bm25`, язык russian) → RRF; кандидаты всех коллекций → реранкер bge-reranker-v2-m3 →
порог и отбор (§10.4). Отказ стадии не ломает ответ, а попадает в трассировку и инциденты.

## Альтернативы

Только векторный поиск — см. контекст. Свой BM25 вне Qdrant — запасной вариант (fastembed `Bm25`,
переключатель `bm25.provider`).

## Последствия

Нужен Qdrant ≥ 1.15.3 (в compose — v1.19.2). Параметры поиска меняются только по результатам
`eval/rag` (hit@5, MRR для четырёх конфигураций, §10.6).
