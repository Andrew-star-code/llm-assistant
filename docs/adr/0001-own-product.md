# 0001. Собственный продукт, а не форк готового чата

- Статус: принято
- Дата: 2026-10-31

## Контекст

Нужны функции, которых нет в готовых чатах: скрытый репорт о нарушениях, просмотр удалённых
сообщений админом, инциденты с логами, RAG с ролями из AD, семантический слой SQL. Плюс требование
подробной документации собственного кода (§17).

## Решение

Пишем собственный продукт: модульный монолит на FastAPI + React SPA (§2).

## Альтернативы

- Форк Open WebUI: с v0.6.6 брендинг нельзя менять без enterprise-лицензии при числе
  пользователей больше 50 за 30 дней ([лицензия](https://docs.openwebui.com/license/)); перечисленные
  функции — глубокие правки чужого кода, которые придётся переносить при каждом обновлении.
- LibreChat (MIT): лицензия подходит, но это тот же глубокий форк.

## Последствия

Больше собственного кода, но полный контроль над правами, данными и интерфейсом.
Объём работ разбит на этапы §19; документация — часть Definition of Done.
