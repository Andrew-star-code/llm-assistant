# 0008. LiteLLM Proxy только для разработчиков

- Статус: принято
- Дата: 2026-10-31

## Контекст

2–3 разработчикам нужен OpenAI-совместимый доступ к модели кодинга из IDE с персональными ключами,
лимитами и журналом (§3.4).

## Решение

Отдельный шлюз `dev-gateway` на LiteLLM Proxy: виртуальные ключи, RPM/TPM, бюджеты, учёт. Чат через
него не ходит — у чата свои лимиты (§12).

## Альтернативы

Свой шлюз: дублирование готовой функциональности.

## Последствия

Модель разработчиков живёт в отдельном compose-проекте на GPU 2 и меняется без влияния на чат.
