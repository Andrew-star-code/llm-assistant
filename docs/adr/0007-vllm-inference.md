# 0007. vLLM для всех моделей

- Статус: принято
- Дата: 2026-10-31

## Контекст

Нужны параллельная нагрузка (10–20 одновременных генераций), tool calling, отдельное поле
размышлений, prefix caching и метрики (§3).

## Решение

Все модели (чат, кодинг, служебная, guard, эмбеддинги, реранкер) — в vLLM с OpenAI-совместимым API.
Модели адресуются по ролям из `config/models.yaml`, а не по именам.

## Альтернативы

Ollama: слабее под параллельной нагрузкой, меньше контроля над парсерами и памятью GPU. Остаётся
вариантом для ручной проверки на машине разработчика (§16.1).

## Последствия

Код зависит только от OpenAI-совместимого протокола: в разработке те же роли обслуживают fake-llm и
TEI на CPU ([ADR-0010](0010-dev-stand-mocks.md)).
