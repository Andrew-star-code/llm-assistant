# 0005. Qdrant: коллекция на тип данных, права через фильтры payload

- Статус: принято
- Дата: 2026-10-31

## Контекст

Три уровня баз знаний (общие, ролевые, личные) плюс вложения чатов; поиск должен идти по всем
доступным уровням одним запросом, а чужие фрагменты не должны попасть в ответ даже при ошибке модели
(§10.1).

## Решение

Коллекции `kb_chunks`, `personal_chunks` (`owner_id` с индексом `is_tenant`), `attachment_chunks`,
★ `memories`. Фильтр прав строит сервер и передаёт явно в каждый prefetch (§10.4).

## Альтернативы

Коллекция на каждого пользователя: сотни коллекций, накладные расходы памяти, один запрос не может
искать по нескольким уровням.

## Последствия

Обязательные тесты изоляции — отдельно для dense и для BM25 (§18.2).
